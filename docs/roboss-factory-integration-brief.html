สำหรับโรงงานผลิตเครื่องล้างรถ

ข้อมูลที่ต้องขอ เพื่อเชื่อมเครื่องล้างรถเข้ากับแอพ ROBOSS

เป้าหมายคือให้ระบบ ROBOSS สั่งเริ่มล้าง ตรวจสถานะเครื่อง รับ error/progress และบันทึกประวัติลูกค้า คูปอง สแตมป์ และสมาชิกได้แบบอัตโนมัติ

Checklist ที่ต้องได้จากโรงงาน

1

สเปกเครื่องและโหมดล้าง

  • รุ่นเครื่อง จำนวน bay และอุปกรณ์ต่อพ่วง
  • โหมดล้างทั้งหมด เช่น Quick, Shine, Graphene
  • step ของแต่ละโหมดและเวลาต่อ step
  • sensor ที่มี เช่น รถเข้า, ประตู, emergency stop
2

วิธีสั่งงานเครื่อง

  • ใช้ PLC, Relay, ESP32, RS485, Modbus, MQTT หรือ HTTP API
  • คำสั่ง start, pause, stop, reset, maintenance
  • รูปแบบ request / response และตัวอย่างจริง
  • เงื่อนไขก่อนเริ่มล้าง เช่น เครื่องว่างและ safety พร้อม
3

สถานะและ error ที่ส่งกลับ

  • สถานะ idle, reserved, washing, completed, error, offline
  • progress เป็นเปอร์เซ็นต์หรือ step ปัจจุบัน
  • error code พร้อมความหมายทุกตัว
  • event ตอนเริ่มล้าง เสร็จ ยกเลิก หรือหยุดฉุกเฉิน
4

Network และการเชื่อมต่อ

  • เครื่องต่อ LAN, Wi-Fi หรือ 4G router
  • รองรับ IP คงที่, VPN หรือ cloud MQTT หรือไม่
  • heartbeat ส่งทุก 10-30 วินาทีได้ไหม
  • ถ้าเน็ตหลุด เครื่องและระบบต้องทำงานอย่างไร
5

ความปลอดภัยและกันสั่งผิด

  • เครื่องต้องมี machineId และ secret/token ประจำเครื่อง
  • รับคำสั่งเฉพาะ sessionId ที่ถูกต้องจากระบบ ROBOSS
  • reject คำสั่งซ้ำหรือคำสั่งหมดอายุ
  • emergency stop ต้อง override แอพได้ทันที
6

เอกสารที่ต้องส่งให้เรา

  • wiring diagram และ controller manual
  • API document หรือ Modbus register map
  • รายการ command, status, error code ทั้งหมด
  • วิธี update firmware และ contact engineer

Protocol ที่ ROBOSS แนะนำ: MQTT

Topic: roboss/branch/{branchId}/machine/{machineId}/status roboss/branch/{branchId}/machine/{machineId}/event roboss/branch/{branchId}/machine/{machineId}/command Payload: { "machineId": "BAY-01", "sessionId": "session_123", "status": "washing", "step": 2, "progress": 40, "errorCode": null }

สิ่งที่ต้องทดสอบหน้าโรงงาน

  • สั่ง start จากระบบแล้วเครื่องเริ่มจริง
  • เครื่องส่ง progress และ completed กลับมา
  • กด emergency stop แล้ว ROBOSS เห็น event
  • เน็ตหลุดแล้วระบบเห็น offline
  • หลายเครื่องทำงานพร้อมกันได้
  • error code แสดงบนหลังบ้านได้ถูกต้อง
สิ่งสำคัญที่สุดที่ต้องได้กลับมา

Protocol การสั่ง start, รูปแบบ status/event ที่เครื่องส่งกลับ, error code ทั้งหมด, network setup และวิธีทดสอบกับเครื่องจริง
